# 🎬 Movie & TV Web App

A clean, modern, and responsive web application designed for exploring popular movies and TV shows.

🚀 **Live Demo:** [https://stream.sevengigs.online](https://stream.sevengigs.online)

---

## ✨ Features

* 🔍 **Search & Explore:** Easily discover trending movies and TV series.
* 📱 **Fully Responsive:** Optimized for seamless viewing across mobile, tablet, and desktop screens.
* 🎨 **Clean UI/UX:** Simple, modern, and intuitive user interface.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting / Deployment:** GitHub Pages

---

## 💻 Local Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Seven25-ui/Movie_tv.git
   ```

2. **Open the project folder:**
   ```bash
   cd Movie_tv
   ```

3. **Run it:** open `index.html` in your browser.
