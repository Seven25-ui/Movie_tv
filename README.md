# 🎬 Movie & TV Web App

A clean, modern, and responsive web application designed for exploring popular movies and TV shows.

🚀 **Live Demo:** [https://seven25-ui.github.io/Movie_tv/](https://seven25-ui.github.io/Movie_tv/)

---

## ✨ Features

* 🔍 **Search & Explore:** Easily discover trending movies and TV series.
* 📱 **Fully Responsive:** Optimized for seamless viewing across mobile, tablet, and desktop screens.
* 🎨 **Clean UI/UX:** Simple, modern, and intuitive user interface.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting / Deployment:** GitHub Pages
